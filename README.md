## 📌 Sobre o Projeto

Este é um programa de calculadora que realiza diversos tipos de operações com números inteiros. Foi desenvolvido como projeto de aprendizado em Python, com foco em lógica de programação e cálculos matemáticos.

---

## ✨ Funcionalidades

### 🔢 1. MDC — Máximo Divisor Comum

> 
> Encontra o maior número que divide os dois números ao mesmo tempo.

### 🔢 2. MMC — Mínimo Múltiplo Comum

> 
> Encontra o menor número que é múltiplo dos dois números informados.

### ➕ 3. Soma

> 
> Soma dois números à sua escolha.

### ✖️ 4. Multiplicação

> 
> Multiplica dois números à sua escolha.

---

## 🚀 Como Usar

1. Execute o programa
2. Digite os dois números para calcular o **MDC e MMC**
3. Digite os dois números para calcular a **Soma**
4. Digite os dois números para calcular a **Multiplicação**
5. Veja todos os resultados na tela! ✅

> 
> 💡 **Dica:** Você pode usar os mesmos números ou escolher valores diferentes para cada operação — fica a seu critério!

---

## 📝 Exemplo de Uso

```
Digite o número: 12
Digite o número: 22
O MDC é: 2
O MMC é: 132

Digite o número para soma: 10
Digite o número para soma: 20
SOMA É: 30

Digite o número para multiplicar: 2
Digite o número para multiplicar: 3
vezes É: 6
```
